# Contra 2 — Difficulty v9

Game web tự chứa, có gán phím và tay cầm; bản Windows portable đi kèm.

- **[Chơi ngay trên trình duyệt](https://pnkh.github.io/contra2-difficulty-v9/)**
- **[Tải EXE cho Windows 10/11 64-bit](https://pnkh.github.io/contra2-difficulty-v9/downloads/Contra2-Difficulty-v9.exe)** — mở và gán nút, không cần cài giả lập.
- [Hướng dẫn chơi](https://pnkh.github.io/contra2-difficulty-v9/guide.txt)
- [Mã nguồn và giấy phép](https://pnkh.github.io/contra2-difficulty-v9/licenses.html)

Trên web, bấm **CHƠI NGAY**, sau đó **Gán nút** nếu muốn đổi bàn phím hoặc tay cầm.
Mặc định: phím mũi tên di chuyển, **Z** bắn, **X** nhảy, **V** Select, **Enter** Start.
Trong màn chọn: Lên/Xuống đổi LEVEL, A/B đổi STAGE, Trái/Phải chọn 30 mạng hoặc INF.

## Xuất bản bản cập nhật

Chọn **Settings → Pages → Source → GitHub Actions** để xuất bản.
Workflow `.github/workflows/pages.yml` khôi phục các file tĩnh từ ba gói ZIP,
kiểm tra SHA-256 của ROM và xuất bản lên GitHub Pages. Không cần máy chủ riêng.

Các gói ZIP được chia nhỏ để tải qua giao diện GitHub; chúng giữ nguyên
cấu trúc thư mục, mã nguồn, giấy phép và các bản tải trong gói web v9.

ROM v9 SHA-256: `1e0bd4c98a7c2fa0fbf2c32963897f84f395fa43c49ad1ad76526658c446445c`.

Mã nguồn và giấy phép của trình giả lập được kèm trong mục tải về của trang chơi.
